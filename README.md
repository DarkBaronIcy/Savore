# Savoré — Restaurant Website

A responsive, multi-page restaurant website for Savoré, a contemporary Nigerian restaurant concept.

## Included
- Responsive homepage
- Interactive menu filtering
- Full menu page
- Our Story page
- Gallery page
- Contact page
- Reservation form UI
- Contact form UI
- Click-to-call phone link
- WhatsApp link
- Google Maps embed for 13, Osho Street, Shomolu, Lagos
- Mobile navigation
- SEO-friendly titles and descriptions
- Google Fonts
- No build tools or dependencies required

## Run
Open `index.html` directly in a browser, or serve the folder with any static server.

## Important
The reservation and contact forms are frontend demonstrations. They do not send data anywhere until connected to a backend or form service.

The food photography currently uses remote Unsplash image URLs. For a production deployment, replace these with properly licensed restaurant photography stored locally.
